# Learning Center Media Placeholders

This folder contains **placeholder images** referenced by `src/config/learningModules.json`.

Replace any placeholder file with a real screenshot **without changing the path**, and the Learning Center will pick it up automatically.

## Conventions

- Organized by section, then module:
  - `public/images/learning/<section>/<module-id>/...`
- Files are currently 1x1 placeholder PNGs to avoid broken images in the UI.
- Keep filenames stable; treat these paths as the manual's canonical references.
